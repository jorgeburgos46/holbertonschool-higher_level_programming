================================
How to use 5-text_indentation.py
================================

Import function:
    >>> text_indentation = __import__('5-text_indentation').text_indentation

Test basic text with periods:
    >>> text_indentation("Hello. World.")
    Hello.
    <BLANKLINE>
    World.
    <BLANKLINE>

Test with question mark:
    >>> text_indentation("How are you?")
    How are you?
    <BLANKLINE>

Test with colon:
    >>> text_indentation("Name: John")
    Name:
    <BLANKLINE>
    John

Test not a string:
    >>> text_indentation(42)
    Traceback (most recent call last):
    TypeError: text must be a string

Test None:
    >>> text_indentation(None)
    Traceback (most recent call last):
    TypeError: text must be a string

Test empty string:
    >>> text_indentation("")

Test no special characters:
    >>> text_indentation("Hello World")
    Hello World

Test missing argument:
    >>> text_indentation()
    Traceback (most recent call last):
    TypeError: text_indentation() missing 1 required positional argument: 'text'

Test spaces around special chars:
    >>> text_indentation("Hello .   World")
    Hello .
    <BLANKLINE>
    World
