# Python - More Classes and Objects

This project covers Object-Oriented Programming (OOP) in Python 3.

## Learning Objectives
- What is OOP
- What is a class, object, and instance
- Public, protected, and private attributes
- What is `self`
- What is a method
- The special `__init__` method
- Data Abstraction, Encapsulation, and Information Hiding
- Properties vs Getters and Setters
- `__str__` and `__repr__` methods
- Class attributes vs instance attributes
- Class methods and static methods
- `__dict__` of a class and instance
- How to use `getattr`

## Requirements
- Python 3.8.5
- Ubuntu 20.04 LTS
- pycodestyle 2.7.*
